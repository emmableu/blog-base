# 🧠 LeetCode 风格题目：多分类评估指标计算器（class-wise）

---

## 🧾 题目描述

给定一批模型输出的 logits（未归一化分数），和目标标签（使用 one-hot 编码），实现一个函数来计算：

- **准确率 Accuracy**（全对才算对）
- **每类精确率 Precision**
- **每类召回率 Recall**

结果应和 `evaluate` 库对齐，精度误差不超过 `1e-5`。

---

## ✅ 参考实现 solution

```python
import torch
import torch.nn.functional as F
import evaluate

def get_predictions(logits: torch.Tensor, num_classes: int) -> torch.Tensor:
    return F.one_hot(logits.argmax(-1), num_classes=num_classes)

def eval_classwise_metrics(logits: torch.Tensor, target: torch.Tensor):
    num_samples = logits.size(0)
    num_classes = logits.size(-1)
    y_pred = get_predictions(logits, num_classes)
    """
    y_pred
    [[0, 1, 0],
     [1, 0, 1]]
     
    target
    [[0, 1, 1],
     [1, 1, 0]]
     
     class0: acc = 1, prec = 1, rec = 1
     class1: acc = 0.5, prec = 1, recall = 0.5
     class2: acc = 0, prec = 0, recall = 0
    """
    tp = (y_pred * target).sum(dim=0, keepdim=True)  # size: (1, 3)
    fp = (y_pred * (1 - target)).sum(dim=0, keepdim=True)  # size: (1, 3)
    fn = ((1 - y_pred) * target).sum(dim=0, keepdim=True)  # size: (1, 3)

    prec = tp / (tp + fp + 1e-10)
    rec = tp / (tp + fn + 1e-10)
    """
    note here we assume using evaluate package's way of calculating acc,
    it can only calculate global accuracy
    """

    compare = y_pred == target
    correct = (compare.sum(dim=-1) == num_classes).sum()
    acc = correct/num_samples
    return acc.item(), prec.squeeze().tolist(), rec.squeeze().tolist()

```

## 📎 提示

- 使用 `F.one_hot(logits.argmax(-1), num_classes=...)` 将预测转为 one-hot 格式
- dim=0 表示按类别求和
- 加上 `1e-10` 是为了防止除以 0
- `acc` 是“完全对的样本数”除以总样本数
