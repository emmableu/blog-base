
# ✅ 交叉熵损失（Cross Entropy Loss）详解

---

本文件通过示例和问答形式，详细解释交叉熵的定义、用途、以及为什么它在深度学习中如此重要。

---

## 📌 什么是交叉熵损失？

交叉熵衡量的是两个概率分布之间的差异。对于分类任务来说，它衡量模型预测的概率分布（softmax 后）与真实标签分布之间的距离。

---

## ❓ Q1：交叉熵损失的公式是什么？

对于一个样本，交叉熵损失为：

$$
\mathcal{L} = -\log(p_y)
$$

![](https://raw.githubusercontent.com/emmableu/image/master/202506141033506.png)
其中：

- \( p_y \)：模型对真实类别 \( y \) 的预测概率（来自 softmax）
- 当 \( x \) 趋近于 1，损失趋近于 0（预测正确）
- 当 \( x \) 趋近于 0，损失趋近于 ∞（预测错误）

---

## 📊 关键点表格

| x 值    | -log(x)  |
|---------|----------|
| 1.0     | 0.000    |
| 0.99    | 0.01005  |
| 0.9     | 0.10536  |
| 0.5     | 0.6931   |
| 0.1     | 2.3026   |
| 0.01    | 4.6052   |
| 0.001   | 6.9078   |

---

## 🧠 直观解释

- ✅ 如果模型预测某一类别的概率为 **0.99**，真实标签也正是该类别，那么损失为 `-log(0.99) ≈ 0.01`，非常小。
- ❌ 如果模型只给真实类别 **0.01 的概率**，那么损失为 `-log(0.01) ≈ 4.6`，惩罚很大。


---

## ❓ Q2：举个例子？

假设你有三个类别，模型的预测概率如下：

```
类别 0: 0.1
类别 1: 0.7 ✅（真实标签）
类别 2: 0.2
```

则交叉熵损失为：

$$
\mathcal{L} = -\log(0.7) \approx 0.3567
$$

---

## ❓ Q3：为啥要取对数（log）？

原因有三个：

1. **放大错误**：如果模型对真实类别预测概率很小，比如 0.01，那 `-log(0.01) ≈ 4.6`，惩罚很大。这会鼓励模型提高正确预测的概率。

2. **更好的梯度表现**：
   - 线性函数梯度恒定，优化效果差。
   - 对数函数曲线陡峭 → 梯度较大 → 优化更快。

3. **数学简洁性**：与 softmax 联合使用后，公式简化为：
   $$
   -z_y + \log(\sum_j e^{z_j})
$$
   （其中 \( z_y \) 是真实类的 logit）

---

## ❓ Q4：不用 log 可不可以？比如用平方误差？

可以，但效果差：

- **平方误差（MSE）** 在分类中不稳定，不能有效区分概率之间的微妙差异。
- MSE 假设误差是对称的（e.g., 预测 0.1 vs 0.9 的差距一样），而分类问题不是对称的。

结论：分类问题 → **交叉熵更合适**。

---

## ❓ Q5：交叉熵是怎么参与梯度下降的？

训练神经网络时，我们的目标是最小化损失函数。交叉熵的导数在 softmax 的基础上非常自然，计算如下：

- 假设 softmax 输出为 \( p_i \)，目标为 \( y_i \)
- 对损失函数求导得到：
  $$
  \frac{\partial L}{\partial z_i} = p_i - y_i
  $$

这个结果非常简单直接，计算效率高，而且梯度大小与预测误差成正比，非常适合用于反向传播（backpropagation）。

    $$L = -log(p_y)$$

## Implementation
```python
import torch
import torch.nn.functional as F

def manual_cross_entropy(logits: torch.Tensor, target: torch.Tensor) -> torch.Tensor:
    exponential = torch.exp(logits)
    probs = exponential/exponential.sum(dim=-1, keepdim=True)
    neg_log = - torch.log(probs[torch.arange(probs.size(0)), target])
    return neg_log

```
