# 🎯 使用 PyTorch 从概率分布中采样多个元素

## 🧪 题目描述：根据概率分布采样多次

实现一个函数 `sample_n_times(probs: List[float], n: int) -> List[int]`，根据给定的概率向量 `probs` 从索引 `[0, 1, ..., len(probs)-1]` 中采样 `n` 次，并返回结果列表。

你可以假设 `probs` 是一个归一化的概率分布（所有元素相加约等于 1）。

---

## 📥 输入示例：

```python
probs = [0.2, 0.5, 0.3]
n = 10
```

---

## 📤 输出示例：

```python
[1, 1, 2, 0, 1, 2, 1, 1, 1, 0]
```

> 注意：每次运行结果不同，但整体频率应接近 `[0.2, 0.5, 0.3]` 的概率分布。

---

## 🧾 函数签名：

```python
from typing import List

def sample_n_times(probs: List[float], n: int) -> List[int]:
```

---

## ✅ 解法代码（推荐方式：使用 `torch.distributions.Categorical`）

```python
import torch
from typing import List

def sample_n_times(probs: List[float], n: int) -> List[int]:
    # 将概率列表转为 tensor，确保 float 类型
    probs_tensor = torch.tensor(probs, dtype=torch.float)

    # 创建离散分布对象
    dist = torch.distributions.Categorical(probs=probs_tensor)

    # 从分布中采样 n 次，返回形状为 (n,)
    samples = dist.sample((n,))

    # 转换为 Python 原生列表返回
    return samples.tolist()
```

---

## 🔍 方法说明：

| 步骤 | 说明 |
|------|------|
| `torch.tensor(probs)` | 转为 float 类型的张量 |
| `Categorical(probs=...)` | 创建多项分布（根据概率） |
| `.sample((n,))` | 采样 `n` 次，返回 shape=(n,) 的张量 |
| `.tolist()` | 转为 Python 原生列表返回 |
注意：
`probs` 不需要加起来是1，torch 会把 比如 0.3, 0.3 变成0.5， 0.5

```python
dist = torch.distributions.Categorical(probs=torch.tensor([0.5, 0.5]))
samples = dist.sample((100,))
```

和下面这个是一样的

```python
dist = torch.distributions.Categorical(probs=torch.tensor([0.3, 0.3]))
samples = dist.sample((100,))
```

# 🎯 使用 `torch.distributions.Categorical` 批量处理 2D 概率张量

## ✅ 概要

PyTorch 的 `Categorical` 分布支持 **二维张量作为输入**，每一行被视为一个独立的概率分布。这对于**批量处理多个样本**或**序列模型中的每个时间步**非常有用。

---

## 📥 示例 1：对多个分布各采样一次

```python
import torch

# 每一行表示一个不同的概率分布
probs = torch.tensor([
    [0.1, 0.9],
    [0.5, 0.5],
    [0.3, 0.7],
], dtype=torch.float)

# 创建分类分布对象
dist = torch.distributions.Categorical(probs=probs)

# 每行采样 1 次，结果 shape: (3,)
samples = dist.sample()
print(samples)  # 输出示例: tensor([1, 1, 0])
```

---

## 📥 示例 2：每个分布采样多次

```python
# 从每行采样 5 次，结果 shape: (5, 3)
samples = dist.sample((5,))
print(samples)
```

输出格式如下：

```
# tensor([[1, 0, 1],  
#         [1, 0, 0],  
#         [1, 0, 0],  
#         [1, 0, 1],  
#         [1, 0, 1]])
```

---

## 📌 使用说明

| 功能          | 说明                                                  |
| ----------- | --------------------------------------------------- |
| 2D 输入       | 支持，每一行是一个独立分布                                       |
| 每行采样一次      | 使用 `dist.sample()`                                  |
| 每行采样多次      | 使用 `dist.sample((n,))`，输出 shape 为 `(n, batch_size)` |
| 支持 logits   | 可替代 `probs=` 使用 `logits=` 参数                        |
| 要求非负且总和 > 0 | 每一行都必须至少有一个正数，不能是全 0                                |


---

## ⚠️ 注意事项：

- output shape 是 `[5, 3]`， 不是 `[3, 5]`
- 如果 `probs` 含全 0，会抛出错误
- 可用 `logits=` 替代 `probs=` 进行 softmax 操作

---

## ✅ 示例调用与输出：

```python
import torch  
prob_tensor = torch.tensor([0.3, 0.7])  
dist = torch.distributions.Categorical(prob_tensor)  
out = dist.sample((1000,))  
  
count_0 = (out == 0).sum().item()  
count_1 = (out == 1).sum().item()  
print(count_0, count_1)  
# 296 704
```

---

# 🔧 拓展功能：添加对 `logits` 的支持（use_logits=True）

在某些情况下，我们并不直接处理“概率分布”（probs），而是处理未经 softmax 的原始 logits（对数几率）。为了增强采样函数的灵活性，我们可以添加一个 `use_logits` 参数，让用户选择输入是概率还是 logits。



## ✅ 修改后的实现代码

```python
import torch

logits_tensor = torch.tensor([30, 70])
dist = torch.distributions.Categorical(logits=logits_tensor)
print(dist.probs)
out = dist.sample((1000,))

count_0 = (out == 0).sum().item()
count_1 = (out == 1).sum().item()
print(count_0, count_1)

# output:
# tensor([4.2484e-18, 1.0000e+00])
# 0 1000
```

---

## 🔍 方法说明

| 参数           | 说明                         |
| ------------ | -------------------------- |
| `logits=`    | PyTorch 会自动对其执行 softmax 运算 |
| `probs=`     | 假设输入已归一化为概率向量              |

---

## ⚠️ 注意事项

- **logits 可以是任意实数**，无需归一化，模型输出通常是 logits
- 不要同时传入 `probs=` 和 `logits=`，只能用其一
- logits 更适合深度学习模型 pipeline（如 transformer、语言建模）
