
# PyTorch 张量扩展学习：`repeat` vs `expand`

本文比较了 PyTorch 中两个常用张量扩展方法：`repeat` 和 `expand`，包括基本语法、多个例子、输出解释及断言测试。

---

## ✅ Section 1: `torch.repeat` — s重复复制张量数据

### 📘 基本语法

```python
x.repeat(dim0_repeat, dim1_repeat, ...)
```

- 会复制张量的数据内容，**实际占用内存**
- 重复次数需要与张量维度相同
- output shape == input_shape * repeat shape

---

### 🧪 示例表格

| 输入 `x`       | imput dim | `repeat(...)`  | output dim | 输出结果                            | 解释              |
| ------------ | --------- | -------------- | ---------- | ------------------------------- | --------------- |
| `[[1, 2]]`   | (1, 2)    | `repeat(2, 3)` | (2, 6)     | `[[1,2,1,2,1,2],[1,2,1,2,1,2]]` | 第0维复制2次，第1维复制3次 |
| `[[5], [6]]` | (2, 1)    | `repeat(1, 4)` | (2, 4)     | `[[5,5,5,5],[6,6,6,6]]`         | 每行复制4次          |
| `[1, 2]`     | (2,)      | `repeat(3)`    | (6,)       | `[1,2,1,2,1,2]`                 | 1D张量，复制3次       |

## ✅ Section 2: `torch.expand` — 广播视图，不复制数据

### 📘 基本语法

```python
x.expand(new_shape)
```

- 创建新视图，**不复制数据**， 只复制它存储的位置
- **只能扩展原本维度为 `1` 的地方**
- the output shape == new_shape

什么叫不复制数据： 看下面的例子
```python
x = torch.tensor([[1], [2]])  # shape: (1, 2)  
out = x.expand(2, 3)  
print(out)  
# tensor([[1, 1, 1],  
#         [2, 2, 2]])  
out[1,2] = 9  
print(out)  
# tensor([[1, 1, 1],  
#         [9, 9, 9]])
```

---

### 🧪 示例表格

| 输入 `x`       | input dim | `expand(...)`  | output dim | 输出结果                | 解释                    |
| ------------ | --------- | -------------- | ---------- | ------------------- | --------------------- |
| `[[1], [2]]` | (2, 1)    | `expand(2, 3)` | (2, 3)     | `[[1,1,1],[2,2,2]]` | 第二维为1，可扩展为3           |
| `[7]`        | (1, )     | `expand(3)`    | (3, )      | `[7, 7, 7]`         | 标量扩展                  |
| `[[10]]`     | (1, 1)    | `expand(2, 2)` | (2, 2)     | `[[10,10],[10,10]]` | shape (1,1) 扩展到 (2,2) |
