# 🔄 `torch.randperm()` 使用指南（问答 + 示例）

`torch.randperm(n)` 是 PyTorch 中一个非常常用的函数，通常用于对数据进行 **打乱（shuffle）**。

---

## ❓ Q1: 什么是 `torch.randperm(n)`？

**答：**
`torch.randperm(n)` 会返回一个从 0 到 n-1 的所有整数的乱序排列。

---

## 🧪 Q2: 最基础的例子？

```python
import torch
idx = torch.randperm(5)
print(idx)
```

**可能输出：**
```
tensor([2, 4, 1, 0, 3])
```

**解释：**
这表示 `[0, 1, 2, 3, 4]` 被打乱成了 `[2, 4, 1, 0, 3]`。

---

## 🧪 Q3: 用于打乱数据张量？

```python
X = torch.tensor([[10, 20], [30, 40], [50, 60]])
idx = torch.randperm(X.size(0))
X_shuffled = X[idx]
print(X_shuffled)
```

**输出：**
```
可能是：
tensor([[30, 40],
        [10, 20],
        [50, 60]])
```

**解释：**
我们根据乱序索引 `idx`，对 X 的行进行了重排（打乱）。

---

## 🧪 Q4: 同时打乱 X 和 y？

```python
X = torch.tensor([[1, 2], [3, 4], [5, 6]])
y = torch.tensor([0, 1, 2])

idx = torch.randperm(X.size(0))
X_shuffled = X[idx]
y_shuffled = y[idx]

print(X_shuffled)
print(y_shuffled)
```

**解释：**
通过使用相同的打乱索引 `idx`，我们同时打乱了特征和标签，确保数据仍一一对应。

---

## 🧪 Q5: 高维数据也能打乱吗？

```python
X = torch.randn(100, 64)  # 100 个样本，每个样本 64 维
idx = torch.randperm(100)
X = X[idx]
```

当然可以，`torch.randperm` 始终只影响第 0 维（行维度）！

---

## 🧠 小结

| 用法       | 示例                                 |
| -------- | ---------------------------------- |
| 打乱索引生成器  | `idx = torch.randperm(n)`          |
| 打乱张量行顺序  | `X = X[torch.randperm(X.size(0))]` |
| 同步打乱多个张量 | 使用相同 `idx` 对多个张量索引                 |

你可以用它在训练前对数据集进行打乱操作，使模型更稳健。
