# PyTorch `nn.Sequential` 使用教程

## 🎯 学习目标

- 理解 `torch.nn.Sequential` 的定义方式与使用场景  
- 掌握如何向 `Sequential` 添加模块、嵌套结构等技巧  
- 掌握如何调试 `Sequential`，例如查看每一层的输出、结构等  
- 熟悉使用方式差异（传参 vs `OrderedDict`）与输出结构  
- 掌握调试技巧如 `print(model)`、使用 `forward_hook` 等  

## 🔍 核心 API 表格

| 功能 | 用法 | 示例输入 | 示例输出 | 说明 |
|------|------|----------|----------|------|
| 定义顺序网络 | `nn.Sequential(layer1, layer2, ...)` | - | 顺序模型 | 直接传入模块 |
| 命名层定义 | `nn.Sequential(OrderedDict([...]))` | - | 含层名模型 | 便于调试 |
| 模型打印 | `print(model)` | - | 网络结构 | 每一层都可见 |
| 调用 | `model(x)` | `x=[B, C, H, W]` | 输出张量 | 自动按顺序执行 |
| 添加层（不可变） | `model.add_module("name", layer)` | - | - | 修改后生效 |
| 查看某层输出 | `register_forward_hook` | - | 输出中间值 | 常用于调试 |

## 💡 小技巧

| 技巧                  | 示例                                                                              | 说明                           |
| ------------------- | ------------------------------------------------------------------------------- | ---------------------------- |
| 嵌套 Sequential       | `nn.Sequential(nn.Conv2d(...), nn.Sequential(nn.ReLU(), nn.BatchNorm2d(...)))`  | 模块结构清晰                       |
| 使用 OrderedDict 命名每层 | `nn.Sequential(OrderedDict([("conv1", nn.Conv2d(...)), ("relu1", nn.ReLU())]))` | `model["conv1"]` 不行，但打印层名更清晰 |
| 输出中间结果              | `hook = layer.register_forward_hook(hook_fn)`                                   | 用于调试中间层输出                    |
| 打印每层输出形状            | 在 `hook_fn` 中 `print(output.shape)`                                             | 辅助调试                         |

## 🧪 LeetCode 风格练习题

### ❓题目：打印 `Sequential` 每一层的输出维度

#### 输入示例：
```python
Sequential 模型：
nn.Sequential(
    nn.Linear(4, 8),
    nn.ReLU(),
    nn.Linear(8, 2)
)

输入张量：
torch.randn(5, 4)
```

#### 输出示例：
```text
After layer 0 (Linear): torch.Size([5, 8])
After layer 1 (ReLU): torch.Size([5, 8])
After layer 2 (Linear): torch.Size([5, 2])
```

### 🧩 函数定义（你需要实现）

```python
def print_sequential_shapes(model: torch.nn.Sequential, x: torch.Tensor) -> None:
    ...
```

### ✅ 可用的断言测试（Assert）

```python
model = torch.nn.Sequential(
    torch.nn.Linear(4, 8),
    torch.nn.ReLU(),
    torch.nn.Linear(8, 2)
)
x = torch.randn(5, 4)
print_sequential_shapes(model, x)
```

## ✅ 解法（打印中间层输出维度）

```python
def print_sequential_shapes(model: torch.nn.Sequential, x: torch.Tensor) -> None:
    for idx, layer in enumerate(model):
        x = layer(x)
        print(f"After layer {idx} ({layer.__class__.__name__}): {x.shape}")
```

## ✅ 高阶技巧：用 Hook 打印中间层输出

```python
def register_hooks(model: torch.nn.Sequential):
    for idx, layer in enumerate(model):
        def hook_fn(module, input, output):
            print(f"[Hook] {module.__class__.__name__}: {output.shape}")
        layer.register_forward_hook(hook_fn)
```

调用方式：
```python
model = torch.nn.Sequential(
    torch.nn.Linear(4, 8),
    torch.nn.ReLU(),
    torch.nn.Linear(8, 2)
)
register_hooks(model)
_ = model(torch.randn(5, 4))
```

## 🧠 总结（高效使用 Sequential）

- ✅ 用 `OrderedDict` 给每一层命名，打印更清晰  
- ✅ 想查看中间层输出？用 `forward_hook` 或手动 forward  
- ✅ 不能用 `model["conv1"]`，要用 `model[0]` 下标  
- ✅ 不能直接 `add_module` 改变已有结构，要重新构造 Sequential

## 🌀 进阶技巧：注册 Backward Hook 查看反向传播梯度

### 使用 `register_full_backward_hook`（推荐）

```python
def register_backward_hooks(model: torch.nn.Sequential):
    for idx, layer in enumerate(model):
        def hook_fn(module, grad_input, grad_output):
            print(f"[Backward Hook] {module.__class__.__name__}: grad_output = {grad_output[0].shape}")
        layer.register_full_backward_hook(hook_fn)
```

### 示例调用

```python
model = torch.nn.Sequential(
    torch.nn.Linear(4, 8),
    torch.nn.ReLU(),
    torch.nn.Linear(8, 2)
)

register_backward_hooks(model)

x = torch.randn(5, 4, requires_grad=True)
output = model(x)
loss = output.mean()
loss.backward()
```

> 🔍 `register_full_backward_hook` 是从 PyTorch 1.8 起推荐使用的方式，避免旧版 `register_backward_hook` 中可能丢失 grad 的问题。

### 提示

- `grad_input`: 是当前层输入的梯度（tuple of tensors）
- `grad_output`: 是当前层输出的梯度（tuple of tensors）
- 为了避免闭包问题，推荐使用 `functools.partial` 或在 hook 中绑定局部变量
