# 📘 `torch.full()` 使用指南（问答 + 示例）

---

## ❓ Q1: `torch.full()` 是什么？

**答：**  
`torch.full(size, fill_value)` 创建一个指定形状的张量，其中所有元素都被设置为同一个 **常数值**。

---

## 🧪 Q2: 创建一个全是 5 的向量？

```python
import torch

x = torch.full((4,), 5)
print(x)
```

**输出：**
```
tensor([5, 5, 5, 5])
```

---

## 🧪 Q3: 创建一个 2×3 的张量，每个元素都是 0.7？

```python
x = torch.full((2, 3), 0.7)
print(x)
```

**输出：**
```
tensor([[0.7000, 0.7000, 0.7000],
        [0.7000, 0.7000, 0.7000]])
```

---

## 🧪 Q4: 指定数据类型和设备？

```python
x = torch.full((2, 2), 1.0, dtype=torch.float64, device='cpu')
print(x)
```

**输出：**
```
tensor([[1., 1.],
        [1., 1.]], dtype=torch.float64)
```

---

## 🧪 Q5: 用于创建概率矩阵？

比如我们要构造 1000 × 27 的概率张量，概率都为 0.5：

```python
probs = torch.full((1000, 27), 0.5)
```

这就很适合用于二分类或多分类初始化。

---

## ✅ 总结

| 功能                | 示例                                     |
| ----------------- | -------------------------------------- |
| 填充整形张量            | `torch.full((3, 3), 1)`                |
| 填充浮点张量            | `torch.full((2, 4), 0.3)`              |
| 用于生成常数概率矩阵        | `torch.full((1000, 27), 1/27)`         |
| 支持指定 dtype/device | `dtype=torch.float32`, `device="cuda"` |
