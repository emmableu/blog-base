# 📘 PyTorch 中的张量运算符：@、`*`、matmul 全解析（含示例）

---

在使用 PyTorch 或 NumPy 进行神经网络或矩阵运算时，常会遇到以下操作符：

- `@`：矩阵乘法（Matrix Multiplication）
- `*`：逐元素相乘（Element-wise Multiplication）
- `matmul()`：显式矩阵乘法函数
- `mul()`：逐元素乘法函数

本文件将逐一讲解每个运算符的作用、使用场景和示例。

---

## 🧮 1. `@` 运算符（矩阵乘法）

等价于 `torch.matmul(A, B)`。  
注意：**不是逐元素相乘，而是线性代数中的矩阵乘法规则。**

### 示例：

```python
import torch

A = torch.tensor([[1, 2], [3, 4]])  # 2x2
B = torch.tensor([[5, 6], [7, 8]])  # 2x2

"""
A:
[[1, 2],
 [3, 4]]
B:
[[5, 6],
 [7, 8]]
"""

C = A @ B
print(C)
```

**输出：**
```
tensor([[19, 22],
        [43, 50]])
```

**解释：**
- 第一行：[1*5 + 2*7, 1*6 + 2*8] = [19, 22]
- 第二行：[3*5 + 4*7, 3*6 + 4*8] = [43, 50]

---

## 🔗 2. `*` 运算符（逐元素相乘）

也称为 Hadamard 乘法，要求两个张量形状一样（或可广播）。

### 示例：

```python
A = torch.tensor([[1, 2], [3, 4]])
B = torch.tensor([[5, 6], [7, 8]])
"""
A:
[[1, 2],
 [3, 4]]
B:
[[5, 6],
 [7, 8]]
"""

C = A * B
print(C)
```

**输出：**
```
tensor([[ 5, 12],
        [21, 32]])
```

**解释：**
- 每个元素逐个相乘：`[1*5, 2*6, 3*7, 4*8]`

---

## 🧾 3. `torch.matmul()`

和 `@` 等价，适合用于更灵活或函数式写法场景。支持高维张量。

### 示例：

```python
A = torch.randn(10, 5)
B = torch.randn(5, 3)

C = torch.matmul(A, B)
print(C.shape)  # [10, 3]
```

---

## 🧾 4. `torch.mul()`（逐元素乘法）

与 `*` 等价，但作为函数使用，适合链式操作。

```python
A = torch.tensor([1, 2, 3])
B = torch.tensor([4, 5, 6])

C = torch.mul(A, B)
print(C)  # tensor([4, 10, 18])
```

---

## ✅ 总结比较

| 运算符 / 函数    | 操作类型         | 要求维度一致？ | 含义                         |
|------------------|------------------|----------------|------------------------------|
| `@`              | 矩阵乘法         | A列数 = B行数  | 线性代数中的乘法             |
| `*`              | 逐元素乘法       | ✅ 或可广播     | 对应元素乘                   |
| `torch.matmul()` | 矩阵乘法函数     | 同 `@`         | 支持高维操作                 |
| `torch.mul()`    | 逐元素乘法函数   | 同 `*`         | 链式结构更清晰               |

---

## 🧠 记忆小技巧

- 如果你是做线性代数或神经网络中的权重乘法，**用 `@` 或 `matmul`**
- 如果你在做损失函数中逐点相乘或 masking，**用 `*` 或 `mul`**
