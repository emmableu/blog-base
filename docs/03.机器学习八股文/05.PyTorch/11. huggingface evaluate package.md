注意：
- 要记忆api怎么用

如果input是 `[0, 1, 2, 1, 2]`:
- 要写average=None （或者micro或者macro）
- 不能写config_name='multilabel'

如果input是 `[[0, 1, 0], [1, 0, 0]])`
- 要写average=None（或者micro或者macro）
- 也要写config_name='multilabel'

对于以上两种情况，accuracy都不能写average=xxx，只有precision，recall要写average=xxx，
accuracy 
- 只能计算全局，不能用average=None计算by label的结果
- 如果每个类别有多个prediction class（e.g.， topic classification，既可能是topic1也可能是topic2），那么必须所有的prediction都是和target一致，才是对的


singlelabel （每一个sample只能是一个类别，比如sentiment analysis，bad good neutral 必须三选一）

全局：
```python
import evaluate
preds = [0, 1, 2, 1, 2] # 也可以是torch.tensor
targets = [0, 2, 1, 1, 2]

accuracy_metrics = evaluate.load('accuracy')
precision_metrics = evaluate.load('precision')
recall_metrics = evaluate.load('recall')

acc = accuracy_metrics.compute(predictions=preds, references=targets) #must include predictions, references, the doc says "Usage of positional arguments is not allowed to prevent mistakes."
prec = precision_metrics.compute(predictions=preds, references=targets, average=None)
recall = recall_metrics.compute(predictions=preds, references=targets, average=None)
print(acc, prec, recall)
# {'accuracy': 0.6} {'precision': array([1. , 0.5, 0.5])} {'recall': array([1. , 0.5, 0.5])}
```


multilabel:
1. must load the metrics using config_name='multilabel'

```python
import evaluate
preds = [[0, 1, 0],
     [1, 0, 0]]

targets =  [[0, 1, 0],
     [0, 1, 0]]

accuracy_metrics = evaluate.load('accuracy', config_name='multilabel')
precision_metrics = evaluate.load('precision', config_name='multilabel')
recall_metrics = evaluate.load('recall', config_name='multilabel')

acc = accuracy_metrics.compute(predictions=preds, references=targets) #must include predictions, references, the doc says "Usage of positional arguments is not allowed to prevent mistakes."
prec = precision_metrics.compute(predictions=preds, references=targets, average=None)
recall = recall_metrics.compute(predictions=preds, references=targets, average=None)
print(acc, prec, recall)
# {'accuracy': 0.5} {'precision': array([0., 1., 0.])} {'recall': array([0. , 0.5, 0. ])}
```

注意accuracy的结果是全局的，而且如果每个类别有多个prediction class（e.g.， topic classification，既可能是topic1也可能是topic2）那么必须所有的prediction都是和target一致，才是对的

```python
import evaluate
import torch
preds = torch.tensor(
    [[0, 1, 1],
     [1, 0, 1]])

targets = torch.tensor(
    [[0, 1, 1],
     [0, 1, 1]])

accuracy_metrics = evaluate.load('accuracy', config_name='multilabel')
precision_metrics = evaluate.load('precision', config_name='multilabel')
recall_metrics = evaluate.load('recall', config_name='multilabel')

acc = accuracy_metrics.compute(predictions=preds, references=targets) #must include predictions, references, the doc says "Usage of positional arguments is not allowed to prevent mistakes."
prec = precision_metrics.compute(predictions=preds, references=targets, average=None)
recall = recall_metrics.compute(predictions=preds, references=targets, average=None)
print(acc, prec, recall)
# {'accuracy': 0.5} {'precision': array([0., 1., 1.])} {'recall': array([0. , 0.5, 1. ])}
```
