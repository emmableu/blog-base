TrainingArguments 参数汇总表：

因为总共有100多个参数，所以要记忆下面这几个参数，不然很难记住要哪些重要参数

| 参数名                         | 作用           | 说明/建议                    |
| :-------------------------- | :----------- | :----------------------- |
| output_dir                  | 模型输出目录       | 例如："./results"           |
| num_train_epochs            | 训练轮数         | 整数，控制整个数据集遍历次数           |
| per_device_train_batch_size | 每设备训练batch大小 | 取决于显存大小，建议8/16/32        |
| per_device_eval_batch_size  | 每设备验证batch大小 | 可与训练一致或更大                |
| evaluation_strategy         | 评估频率策略       | "no" / "steps" / "epoch" |
| logging_steps               | 日志记录步长       | 每隔几步输出loss等指标            |
| save_strategy               | 模型保存策略       | "no" / "epoch" / "steps" |


Trainer 参数汇总表

| 参数名          | 作用         | 说明/建议                                                |
|:--------------- |:------------ |:-------------------------------------------------------- |
| model           | 训练的模型   | 必须是一个 nn.Module，支持 forward(input, labels)        |
| args            | 训练参数     | 必须是 TrainingArguments 实例                            |
| train_dataset   | 训练数据集   | PyTorch Dataset，返回 {'input':..., 'labels':...}        |
| eval_dataset    | 验证数据集   | PyTorch Dataset，用于评估模型性能                        |
| compute_metrics | 评估指标函数 | 一个函数，输入为 EvalPrediction，返回字典（如 accuracy） |
