# PyTorch 张量操作讲解：`.item()`、`.squeeze()`、`.unsqueeze()`

本笔记总结了 PyTorch 中三个常用张量操作：`.item()`、`.squeeze()`、`.unsqueeze()`，包括输入输出示例、类型说明、使用场景。

---

## ✅ `.item()` 和 `.squeeze()` 对比表

| 操作            | 示例张量 `x`                         | 操作代码           | 结果                           | 类型           | 用途说明                                 |
| ------------- | -------------------------------- | -------------- | ---------------------------- | ------------ | ------------------------------------ |
| `item()`      | `x = torch.tensor(5.0)`          | `x.item()`     | `5.0`                        | Python float | 将只有一个元素的标量张量转换成 Python 标量（float、int） |
|               | `x = torch.tensor([7])`          | `x.item()`     | `7`                          | Python int   | 注意只能用于单元素张量，否则报错                     |
| `squeeze()`   | `x = torch.tensor([[1.0]])`      | `x.squeeze()`  | `tensor(1.)`                 | Tensor(0-D)  | 去除所有维度为1的维度，变成标量张量                   |
|               | `x = torch.tensor([[[2.0]]])`    | `x.squeeze()`  | `tensor(2.)`                 | Tensor(0-D)  | 会递归删除所有维度为1的轴                        |
|               | `x = torch.tensor([[1.0, 2.0]])` | `x.squeeze()`  | `tensor([1., 2.])`           | Tensor(1-D)  | 只去除第一个维度，(1, 2) → (2,)               |
|               | `x = torch.randn(1, 3, 1, 5)`    | `x.squeeze()`  | `shape: (3, 5)`              | Tensor(2-D)  | 所有 size 为1 的维度都被移除                   |
| `.squeeze(0)` | `x = torch.tensor([[3.0, 4.0]])` | `x.squeeze(0)` | `tensor([3., 4.])`           | Tensor(1-D)  | 仅尝试去除指定维度（0轴），如果该维度不是1，不会动           |
| ❌ 错误使用        | `x = torch.tensor([1.0, 2.0])`   | `x.item()`     | 报错：多元素 tensor 无法使用 `.item()` | —            | `.item()` 只适用于单元素张量                  |

---

## 🔁 `.unsqueeze()`：增加维度的反操作

`.unsqueeze(dim)` 会在指定维度插入一个大小为 1 的维度，常用于对齐 shape，比如给 CNN 输入加 batch 维。

| 示例张量 `x`        | 操作代码             | 结果张量形状 / 值         | 说明                             |
|---------------------|----------------------|-----------------------------|----------------------------------|
| `tensor([1.0, 2.0])`| `x.unsqueeze(0)`     | `shape: (1, 2)`             | 增加 batch 维                    |
| `tensor([1.0, 2.0])`| `x.unsqueeze(1)`     | `shape: (2, 1)`             | 转成列向量                       |
| `tensor(3.0)`       | `x.unsqueeze(0)`     | `shape: (1,)`               | 标量 → 一维向量                  |
| `tensor([[1.0, 2.0]])` | `x.unsqueeze(2)`  | `shape: (1, 2, 1)`          | 每个元素增加一维                 |

---

## ✅ 使用建议

- `.squeeze()` 和 `.unsqueeze()` 经常配合使用，例如：
  - 把 `[B, C, H, W]` 转换为 `[B, H*W]` 时 `.squeeze()`
  - 推理时对 `[C, H, W]` 加 batch 维 `.unsqueeze(0)`
- `.item()` 用于将标量张量变成 Python 类型（用于日志、print、转 numpy）
