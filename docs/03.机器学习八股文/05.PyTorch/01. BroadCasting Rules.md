知识点回顾：
	•	从**最末尾维度（trailing dimension）**开始逐个比较。
	•	两个维度可广播的条件为：维度相等 / 某一维度为1 / 某一维度不存在（视作1）。
	•	广播后，较小的数组会在逻辑上“扩展”为与大数组相同形状（不复制数据）。


## **问题 1：给出数组形状，判断能否广播**

### **📄 题目描述**

给定两个张量的形状（shape），判断这两个张量是否可以进行广播（broadcasting）。

### **🧪 示例输入输出**
| **示例** | **A 形状**  | **B 形状** | **是否可广播** | **原因简述**           |
| ------ | --------- | -------- | --------- | ------------------ |
| 1      | (2, 3)    | (1,)     | ✅ Yes     | B 维度缺失 → 视为 (1, 1) |
| 2      | (2, 3)    | (2,)     | ❌ No      | 最后维度 3 ≠ 2，且都≠1    |
| 3      | (2, 3)    | (2, 1)   | ✅ Yes     | B 第二维为 1 可扩展       |
| 4      | (2, 3)    | (3,)     | ✅ Yes     | B 视作 (1, 3) 可扩展    |
| 5      | (2, 3)    | (5, 3)   | ❌ No      | 第一维 2 ≠ 5 且都≠1     |
| 6      | (4, 3, 2) | (3, 1)   | ✅ Yes     | 维度自动补 1，并满足扩展规则    |
### **📝 示例 Python 代码（对应示例 2）**
```python
import torch  
a = torch.ones(2, 3)  
print(a.shape, a)  
b = torch.ones(2)  
print(b.shape, b)  
  
print(a + b)
```
output:

### **Code Implementation**

```python
def is_broadcastable(shape_a, shape_b):
	if len(shape_a) != len(shape_b):
		shape_b = [1] * (len(shape_a) - len(shape_b)) + shape_b
	for i in range(len(shape_a)-1, -1, -1):
		if shape_a[i] != shape_b[i]:
			if shape_a[i] == 1 or shape_b[i] == 1:
				continue
			else:
				return False
	return True

# ✅ 示例断言测试
assert is_broadcastable([2, 3], [1]) == True      # 示例 1
assert is_broadcastable([2, 3], [2]) == False     # 示例 2
assert is_broadcastable([2, 3], [2, 1]) == True   # 示例 3
assert is_broadcastable([2, 3], [3]) == True      # 示例 4
assert is_broadcastable([2, 3], [5, 3]) == False  # 示例 5
assert is_broadcastable([4, 3, 2], [3, 1]) == True # 示例 6

print("All tests passed ✅")
```
