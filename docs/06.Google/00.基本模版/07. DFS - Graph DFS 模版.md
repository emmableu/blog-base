## 1. Basic Template
only thing different from tree DFS is that we add `visited` here.  用visited来防止环

```python
def traverse(node: int, graph: List[List], visited: Set):
	if node is None: # edge case, may not be needed
		return
	if node in visited: # this is the additional on top of tree traverse, prevent cycles 防止环
		return
	visited.add(node)
	# 前序位置
	for child in graph[node]:
		traverse(child, graph, visited)
	# 后序位置
```

```python
class Solution:
	def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
		res = []
		self.dfs(0, [0], res, graph)
		return res
		
	def dfs(self, node, cur_path, res, graph):
		if node == len(graph) - 1:
			res.append(cur_path)

		for child in graph[node]:
			self.dfs(child, cur_path + [child], res, graph)
```

## Solution: DFS

```
1 - 2 - 3 - 4
 -----------

如果是树，可以直接copy
图的challenge： 有环

处理环的trick: visited use a dict, visited[old_node] = new_node

然后 visited[old_node(1)] 进去的时候只是单个的1，没有children
4的neighbor遇到1， 返回那个单个的node

然后最后逐步返回后，这个单个的node的object会被populate
所以最后这个会implicitely的update
```


### Solution
```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val = 0, neighbors = None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []
"""
class Solution:
	def cloneGraph(self, node):
		if node is None:
			return None
		return self.dfs(node, {})
	def dfs(self, node, visited):
		if node in visited:
			return visited[node]
		new = Node(node.val)
		visited[node] = new
		new_neighbors = []
		for neighbor in node.neighbors:
			new_neighbors.append(self.dfs(neighbor, visited))
		new.neighbors = new_neighbors
		return new
```

## Solution 1 - DFS

understanding it as a tree problem

```

     |/
  -> 2

input: [[1,2], [2], []]
returns [0, 1, 2]
call graph:
			0   1(cut)   2(cut)
		  /  \
		1     2
	  /
	2
----------------------------------------------
0 -> 1
     
     2
input [[1], [], []]
returns [0, 1, 2]

		   0   1(cut)   2(keep)
		  /
		1
--------------------------------------------------

  0 -> 1
 /|    |/
    2
input [[1], [2], [0]]
returns []

			0   1...(returns before get here)   2...(returns before get here)
		  /
		1
	  /
	2
   /
  0
...
----------------------------------------------------

```

**need to detect cycle using cur_path_set, and save visited in a set**
- unlike cur_path in trees, this cur_path_set does not include the cur_idx, as this is to detect cycles 
- unlike standard graph dfs, here we mark visited at post-order position, this is because if we mark visited during pre-order, than what's supposed to be a cycle will also be marked as visited. 


```python
from collections import defaultdict
class Solution:
    def findOrder(self, numCourses, prerequisites):
        res = []
        visited = set()
        graph = self.build_graph(prerequisites)
        for i in range(numCourses):
            is_dag = self.dfs(i, set(), visited, res, graph)
            if not is_dag:
                return []
        return res

    def build_graph(self, prerequisites):
        graph = defaultdict(list)
        for i, j in prerequisites:
            graph[i].append(j)
        return graph

    def dfs(self, cur_idx, cur_path_set, visited, res, graph):
        if cur_idx in visited: # cut
            return True
        if cur_idx in cur_path_set: # need to first check this
            return False
        for neighbor in graph[cur_idx]:
            is_dag = self.dfs(neighbor, cur_path_set | {cur_idx}, visited, res, graph)
            if not is_dag:
                return False
        res.append(cur_idx)
        visited.add(cur_idx) # unlke typical graph dfs, here we put visited at post-order position, as otherwise, a cyce will be first checked as visited as well and be regarded as valid. 
        return True
