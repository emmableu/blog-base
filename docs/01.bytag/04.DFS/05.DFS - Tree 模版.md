# Understanding Tree Problems

## 0. Basic Template

```python
def traverse(node: TreeNode):
	if node == leaf node:
		return
	# preorder position
	traverse(node.left)
	#mid-order position
	traverse(node.right)
	#post-order position
```

## 1.  pre & post order
### 前序位置：
example 1: 顺序打印
```python
def dfs(nums, i):  
    if i == len(nums):  
        return  
    print(nums[i])  
    dfs(nums, i + 1)
```

example 2: quick sort
https://emmableu.github.io/blog/pages/792a7c/
快速排序的逻辑是，若要对 `nums[lo..hi]` 进行排序，我们先找一个分界点 `p`，通过交换元素使得 `nums[lo..p-1]` 都小于等于 `nums[p]`，且 `nums[p+1..hi]` 都大于 `nums[p]`，然后递归地去 `nums[lo..p-1]` 和 `nums[p+1..hi]` 中寻找新的分界点，最后整个数组就被排序了。

快速排序的代码框架如下：

```python
def quick_sort(nums:List, lo:int, hi:int):
    # p = partition(...) 前序位置，保证p前面都比nums[p]小,p后面都比nums[p]大
    quick_sort(nums, lo, p - 1)
    quick_sort(nums, p + 1, hi)

```

先构造分界点，然后去左右子数组构造分界点，你看这不就是一个二叉树的前序遍历吗？


### 后序遍历：
example 1: 倒序打印
```
def dfs(nums, i):
	if i == len(nums):
		return
	dfs(nums, i + 1)
	print(nums[i])
```
example 2: merge sort
https://emmableu.github.io/blog/pages/792a7c/
再说说归并排序的逻辑，若要对 `nums[lo..hi]` 进行排序，我们先对 `nums[lo..mid]` 排序，再对 `nums[mid+1..hi]` 排序，最后把这两个有序的子数组合并，整个数组就排好序了。

归并排序的代码框架如下：

```python
def merge_sort(nums, lo, hi):
	mid = (lo + hi) // 2
	merge_sort(nums, lo, mid)
	merge_sort(nums, mid+1, hi)
	# 后序位置：合并
	merge(nums, lo, mid, hi)
```



1. 请分析，后序遍历有什么特殊之处？
	1. it has a return value that can come back to the root

2. 请分析，为什么多叉树没有中序遍历？
	1. 中序is between pre and post order


**前中后序是遍历二叉树过程中处理每一个节点的三个特殊时间点**：

前序位置的代码在刚刚进入一个二叉树节点的时候执行；

后序位置的代码在将要离开一个二叉树节点的时候执行；

中序位置的代码在一个二叉树节点左子树都遍历完，即将开始遍历右子树的时候执行。



## 2.  Traverse v.s. Divide&Conquer


- traverse: 传参, and/or make operation (e.g., add 1) at pre-order position
- divide&conquer: 传值，make operation (e.g., add 1) at post-order position. 
	- 后序位置，做divide&conquer的时候，可以利用返回值，让我们在处理当前node的时候知道children的信息
	- divide&conquer的时候，是把问题拆成子问题，e.g., max_depth of a tree 可以利用子数的最大深度返回root的最大深度。 
	- divide&conquer 经常不需要定义一个新的函数，直接用题给函数就能解题



### Example: max depth of binary tree
https://leetcode.cn/problems/maximum-depth-of-binary-tree/

![](https://raw.githubusercontent.com/emmableu/image/master/202506050013577.png)
### traverse solution:

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        return self.dfs(root, 0)
        
    def dfs(self, node: Optional[TreeNode], cur_depth: int) -> int:
        if node is None:
            return cur_depth
        left_depth = self.dfs(node.left, cur_depth + 1)
        right_depth = self.dfs(node.right, cur_depth + 1)
        return max(left_depth, right_depth)
```

### Divide&Conquer solution:
利用子数的最大深度返回root的最大深度

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        left_max_depth = self.maxDepth(root.left)
        right_max_depth = self.maxDepth(root.right)
        return max(left_max_depth, right_max_depth) + 1
```

区别：
- traverse 是+1 从root往leaf传导
- divide&conquer是+1 从leaf往root传导


### 144 - Binary Tree Pre-Order Traversal
https://leetcode.com/problems/binary-tree-preorder-traversal/description/ 

#### Traversal Solution

```python
class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res = []
        self.dfs(root, res)
        return res 
    def dfs(self, node, res):
        if node is None:
            return
        res.append(node.val)
        self.dfs(node.left, res)
        self.dfs(node.right, res)
```


#### Divide & Conquer Solution

**一棵二叉树的前序遍历结果 = 根节点 + 左子树的前序遍历结果 + 右子树的前序遍历结果**。

```python
"""
            1
        /       \
      2           3
     / \
    4   5
[1,2,4,5,3]
e.g., 2,4,5 -> root, left, right
1, (2, 4, 5), 3 -> root, left, right
i.e., for each subtree, it is always root, left, right
"""
class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if root is None:
            return []
        left = self.preorderTraversal(root.left)
        right = self.preorderTraversal(root.right)
        return [root.val] + left + right
```


### 后序位置的特殊之处 Special Points of Post-Order Traversal

前序位置的代码只能从函数参数中获取父节点传递来的数据，而后序位置的代码不仅可以获取参数数据，还可以获取到子树通过函数返回值传递回来的数据。

举具体的例子，现在给你一棵二叉树，我问你两个简单的问题：
1、如果把根节点看做第 1 层，如何打印出每一个节点所在的层数？
e.g., 
```
			1
		/       \
	  2          5
	 / \
	3   4
```

return: `{0:1, 2:1, 3:2, 4:2, 5:1}` 

2、如何打印出每个节点的左右子树各有多少节点？
e.g., 
```
			1
		/       \
	  2          5
	 / \
	3   4
```

return: `{1: 4, 2: 2, 3: 0, 4: 0, 5: 0}`



第一个问题可以这样写代码：

def node_to_level(root: TreeNode):
	res = {}
	self.dfs(root, 0, res)
	return res 
	
def dfs(node: Optional[TreeNode], level: int, res: dict):
	if node is None:
		return
	res[node.val] = level 
	self.dfs(node.left, level + 1, res)
	self.dfs(node.right, level + 1, res)
```

def node_to_count(root: TreeNode):

       if node is None:

## Another problem using postorder position
## 543 - Diameter of Binary Tree
[LC link](https://leetcode.com/problems/diameter-of-binary-tree/)
[explanation](https://leetcode-cn.com/problems/diameter-of-binary-tree/solution/hot-100-9er-cha-shu-de-zhi-jing-python3-di-gui-ye-/)
### 类似题：[n叉树周长](https://emmableu.github.io/blog/pages/430475)


### Description:
Given the root of a binary tree, return the length of the diameter of the tree.
The diameter of a binary tree is the length of the longest path between any two nodes in a tree. This path may or may not pass through the root.
The length of a path between two nodes is represented by the number of edges between them.

Example 1
```
Input: root = [1,2,3,4,5]
1
    - 2
        - 4
        - 5
    - 3
Output: 3
Explanation: 3 is the length of the path [4,2,1,3] or [5,2,1,3].
```
Example 2
```
input: root = [1,2]
output: 1
```

解决这题的关键在于，**每一条二叉树的「直径」长度，就是一个节点的左右子树的最大深度之和**。

root的diameter = max(root.left的深度, root.right的深度）+ 1
先算vertex
所以
node = none: 深度= 0
没有left 和 right的node：深度=1
后面算length用的是edge，所以会比vertex数量少1

但是，对于每一个node，都要额外keep一个max_len，
因为
![](https://raw.githubusercontent.com/emmableu/image/master/202506062052854.png)

它的最长直径是 3，即 `[4,2,1,3]` 或者 `[5,2,1,3]` 这两条「直径」的长度。


## Method

- `max_len`: global 的 max diameter
- dfs 要return：以当前root为root，左，右path中长的那条

## My solution
```python
class Solution:

    def __init__(self):
        self.max_len = 0

    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        self.dfs(root)
        return self.max_len

    def dfs(self, node: Optional[TreeNode]) -> int: # get the maxlen len of *vertex* between left and right
        if node is None:
            return 0
        left = self.dfs(node.left)
        right = self.dfs(node.right)
        self.max_len = max(self.max_len, left + right)
        return max(left, right) + 1
```
