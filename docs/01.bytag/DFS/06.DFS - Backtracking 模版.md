## 回溯算法框架
解决一个回溯问题，实际上就是一个决策树的遍历过程，站在回溯树的一个节点上，只需要思考 3 个问题：

1、路径：也就是已经做出的选择。

2、选择列表：也就是你当前可以做的选择。

3、结束条件：也就是到达决策树底层，无法再做选择的条件。

代码方面，回溯算法的框架：

```python
result = []
def backtrack(路径, 选择列表):
    if 满足结束条件:
        result.add(路径)
        return
    
    for 选择 in 选择列表:
        做选择
        backtrack(路径, 选择列表)
        撤销选择
```

**其核心就是 for 循环里面的递归，在递归调用之前「做选择」，在递归调用之后「撤销选择」**

## 一、全排列问题 permutation
![image](https://user-images.githubusercontent.com/41789327/180926451-275f0424-22a4-4108-b144-54d73e685a2f.png)

```
					/       |       \
					1       2       3
			     / | \
			1(剪枝) 2  3
```

Call graph:

```
   				dfs([1])                     dfs(2)           dfs(3)
				/        \
	      dfs([1,2]) dfs([1,3])
	      /            \
dfs([1,2,3])    dfs([1,3,2]), add [1,3,2] to path_lst before return
add [1,2,3] to path_lst before return
```

- What does `dfs(cur_path)` do:
    - it all of the paths that starts with `cur_path` to the `path_lst`.

Base case:

- `len(cur_path)` = 3, then add to `path_lst`

Additional consideration:

- how do I know only to go to 2 when branching out of 1→3: use a `used` variable.
- 为了不用append再pop，或者加入set然后又从set里面出来，这里直接把参数放在call里面


```python
class Solution:
	def permute(self, nums):
		res = []
		self.dfs([], set(), res, nums)
		return res
	
	def dfs(self, cur_path, used, res, nums):
		if len(cur_path) == len(nums):
			res.append(cur_path)
			return
		for i in range(len(nums)):
			if i not in used:
				self.dfs(cur_path + [nums[i]], used | {i}, res, nums)
```



## Subset

## Description:

Given an integer array nums of unique elements, return all possible subsets (the power set).

The solution set must not contain duplicate subsets. Return the solution in any order.

```
Example 1:

Input: nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]


Example 2:

Input: nums = [0]
Output: [[],[0]]
```



Constraints:

- 1 <= nums.length <= 10
- -10 <= nums[i] <= 10
- All the numbers of nums are unique.

### Solution
- call graph:

```python
                                  dfs(-1, [])
               /                       |                   \
             dfs(0, [1])          dfs(1, [2])            dfs(2, [3])
	        /       \                  | 
		 dfs(1,[1,2]) dfs(2,[1,3])    dfs(2, [2,3])
       /
  dfs(2, [1,2,3])
```

- What does `dfs(cur_idx, cur_path)` do:
    - it adds the `cur_path` into the `path_lst`, and decides whether to add a new element or not:
        - if there's a larger element than the current element, then add that element to cur_path.
- Base case:
    - when there's no larger element than the current element, then go back.

```python
class Solution():
	def subsets(self, nums: List[int]) -> List[int]:
		res = []
		self.dfs(-1, [], res, nums)
		return res
	def dfs(self, cur_idx, cur_path, res, nums):
		res.append(cur_path)
		if cur_idx == len(nums) - 1:
			return 
		for i in range(cur_idx + 1, len(nums)):
			self.dfs(i, cur_path + [nums[i]], res, nums)
```
