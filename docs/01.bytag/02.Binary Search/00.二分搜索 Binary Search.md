## 1. 查找一个在sorted数组中的元素


重点题：
## 704 - Binary Search
https://leetcode.com/problems/binary-search/
![](https://raw.githubusercontent.com/emmableu/image/master/202506081451790.png)
重点： 左闭右闭区间，也就是说：
1. 起始时： l, r = 0, len(nums) - 1
2. 结束时：必须是空区间，如果l == r e.g.，【2，2】那么还有一个元素，所以结束时是 l > r
3. 更新位置时：
	1. 如果nums[mid] < target:
		1. l = mid  + 1, 可以加1，因为是左闭右闭区间，之后能取到l
		2. r = mid - 1， 可以减1，因为是左闭右闭区间，之后能取到r


```python
class Solution:
	def search(self, nums: List[int], target: int) -> int:
		l, r = 0, len(nums) - 1
		while l <= r:
			mid = (l + r) // 2
			if nums[mid] == target:
				return mid
			elif nums[mid] < target:
				l = mid + 1
			elif nums[mid] > target:
				r = mid - 1
		return -1
```

## 2 查找下界 或者 查找插入的位置 或 查找离他最近且>=他的元素的index

左开右开区间 
- init： l = -1, r = len(nums)
- while 条件: l + 1 < r (e.g., (1,2)，中间没有元素)
- 更新: l = mid, r = mid
- return l + 1

### 仅仅查找下界：（等同于` bisect.bisect_left(nums, target)`）

**经典题 find peak element**

- [first bad version](/pages/leetcode278/)
- [Kth missing positive number](/pages/leetcode1539)
- [528-Random Pick with Weight](/pages/f1384b/)

- `nums = [0,1,2,3,4,4,5], target = 4`, 返回4
- `nums = [0,1,2,3,4,4,5], target = 3.5`, 也返回4
- `nums = [0,1,2,3,4,4,5], target = -1` 返回 0
- `nums = [0,1,2,3,4,4,5], target = 10`, 返回7
target > nums[-1] 时会返回 len(target)  
```python
def search(nums, target):
    l, r = -1, len(nums)
    while l + 1 < r:
        mid = (l + r) >> 1
        if nums[mid] < target: # mid < best_pos
            l = mid
        else:
            r = mid
    return l + 1
```

## 3. 查找上界 或 查找离他最近且<=他的元素的index


注意
- *不能*用于查找插入位置，(**和 `bisect.bisect_right` 是不一样的**)
-   查找上界：
	- [Search for a Range](https://leetcode.com/problems/search-for-a-range/)
	- [Find First and Last Position of Element](/pages/fd77d2)
-   查找离他最近且<=他的元素：
	- [divide two integers](/pages/489c53/)
	- [1146 - Snapshot Array](/pages/890177/)

比如： 
- `nums = [0,1,2,3,4,4,5], target = 4`, 返回5
- `nums = [0,1,2,3,4,4,5], target = 10`, 返回6
- `nums = [0,1,2,3,4,4,5], target = 3.5` 返回3 <- 就是这个和bisect_right 不一样 （解释见下面的图）
- `nums = [0,1,2,3,4,4,5], target = 0` 返回0
- `nums = [0,1,2,3,4,4,5], target = -1` 返回-1
target < nums[0] 时会返回 -1
```python
def search(nums, target):
    l, r = -1, len(nums)
    while l + 1 < r:
        mid = (l + r) >> 1
        if nums[mid] <= target: #f(mid) <= target
            l = mid
        else:
            r = mid
    return r - 1
```
