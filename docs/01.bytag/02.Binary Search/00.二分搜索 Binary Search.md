## 1. 查找一个在sorted数组中的元素


重点题：
## 704 - Binary Search
https://leetcode.com/problems/binary-search/
![](https://raw.githubusercontent.com/emmableu/image/master/202506081451790.png)
重点： 左闭右闭区间，也就是说：
1. 起始时： l, r = 0, len(nums) - 1
2. 结束时：必须是空区间，如果l == r e.g.，【2，2】那么还有一个元素，所以结束时是 l > r
3. 更新位置时：
	1. 如果nums[mid] < target:
		1. l = mid  + 1, 可以加1，因为是左闭右闭区间，之后能取到l
		2. r = mid - 1， 可以减1，因为是左闭右闭区间，之后能取到r


```python
class Solution:
	def search(self, nums: List[int], target: int) -> int:
		l, r = 0, len(nums) - 1
		while l <= r:
			mid = (l + r) // 2
			if nums[mid] == target:
				return mid
			elif nums[mid] < target:
				l = mid + 1
			elif nums[mid] > target:
				r = mid - 1
		return -1
```
